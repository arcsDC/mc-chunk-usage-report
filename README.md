# mc-chunk-usage-report

A Fabric mod that displays a live report of loaded chunk counts and memory usage in the debug overlay.

## Stack

Primary language: **Java**

## Project structure

- `src/main/java/com/example/chunkreport/ChunkReportMod.java` — Provides a QoL debug overlay showing server-side chunk statistics for performance monitoring.
- `build.gradle` — fabric mod build config

## Usage

Review the source files and install any dependencies referenced by the project before running it.
